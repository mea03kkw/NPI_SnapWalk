Purpose

Capture engineering build observations during:

  • Engineering Build (EB)
  • Pilot Production (PP)
  • Trial Run
  • Production Line Review
  • Factory Visits

How to Use

  1. Enter build information in Section 1.
  2. Add one observation per issue in Section 2.
  3. Attach one photo per observation.
  4. Enter a clear description for each issue.
  5. Review build result summary in Section 3.
  6. Export the report to Excel.

Photo Rules

  • Maximum 50 photos per report.
  • One photo per observation item.
  • Additional photos require additional observation items.
  • Photos are automatically compressed to reduce file size.

Excel Export

The generated report includes:

  • Main Build Information
  • Observation / Issue Tracking
  • Build Result Summary

Notes

  • Open using Microsoft Edge or Google Chrome.
  • Save exported Excel locally or to your device.
  • Draft saves automatically. Delete saved draft

Purpose

Verify whether a manufacturing process can meet customer demand under planned production conditions.

Suitable for:

  • Engineering Build (EB)
  • Pilot Production (PP)
  • Trial Production
  • Ramp-Up Verification
  • Capacity Validation
  • Manufacturing Readiness Reviews
  • Factory Visits

The tool compares Demand, Plan Capacity and Actual Capacity to identify manufacturing capacity gaps before mass production.

How to Use

  1. Complete Main Build Information

    Enter:

    • Project Name
    • Build Identity
    • Date
    • Auditor Name
    • Factory / Location / Line
    • Special Remark

    This information appears in the Excel report header.

  2. Enter Demand Planning Information

    Provide:

    • Annual Volume
    • Customer Weeks / Year
    • Customer Days / Week
    • Volume Flex
    • Seasonal Flex

    The tool automatically calculates:

    • Base Demand / Week
    • Adjusted Demand / Week
    • DPV (Daily Production Volume)
  3. Set Up Lines

    In Section 3, choose how many lines are active with the "Lines Enabled" dropdown (1â€“5), then for each enabled line enter its Line Identity:

    • Process / Name
    • Location
  4. Configure Planned Capacity

    For each enabled production line enter:

    • Shifts per Day
    • Hours per Shift
    • Break Time
    • Maintenance Time
    • Production Days
    • Production Weeks
    • Changeover Time
    • Inspection Allowance
    • Breakdown Allowance
    • Scrap Rate
    • Machine Cycle Time

    The tool automatically calculates:

    • Planned OEE
    • Required Cycle Time
    • Planned Capacity
    • Plan Ratio
  5. Record Trial Run Results

    For each enabled line enter:

    • Run Duration
    • Downtime
    • Total Parts Run
    • Rejected Parts
    • Actual Cycle Time
    • Notes

    The tool automatically calculates:

    • Actual OEE
    • Actual Weekly Capacity
    • Actual Ratio
    • Actual Capacity Gap
  6. Review Capacity Assessment

    The Capacity Summary compares:

    • Demand
    • Plan Capacity
    • Actual Capacity
    • Status

    Status meanings:

    • Achieved = Actual capacity meets demand
    • Gap = Capacity below demand
    • Major Gap = Significant capacity shortfall

    Important: This is a factual manufacturing-capacity comparison. The tool does not assign PASS or FAIL.

  7. Record Gap Reasons and Actions

    If a line does not meet demand, document:

    • Gap Reason
    • Corrective Action

    These are included in the Excel export.

  8. Export Report

    The Excel export includes:

    • Main Build Information
    • Demand Planning
    • All-Line Capacity Comparison
    • Detailed Line Analysis
    • Machine vs Actual Comparison
    • Capacity Summary
    • Conclusion & Follow-Up

    Supports 1 to 5 enabled production lines.
